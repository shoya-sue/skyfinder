SkyFolder

Cloudflare R2 を macOS Finder にマウントし、URL で共有する

接続情報をアプリ画面に入力するだけで、任意の R2 バケットが Finder のドライブになります。 マウント済みのファイルから恒久公開 URL と期限付き共有 URL をワンクリックで発行できます。 kext もドライバも要りません。

ダウンロード（無料・MIT） ソースコード

何ができるか

  • R2 バケットが Finder のドライブになる — 通常のフォルダと同じように開いて、読み書きできます
  • 恒久公開 URL を発行できる — 公開バケットへアップロードし、カスタムドメインの URL をクリップボードにコピーします
  • 期限付き共有 URL を発行できる — 最大 7 日の presigned URL。一時的に渡したいファイル向けです
  • 公開画像の Exif が自動で消える — GPS・撮影機材・IPTC・PNG のテキストチャンクを除去してから公開します
  • 未送信の件数が見える — クラウドへの反映は即時ではないので、残っている件数をメニューバーに表示します
  • 公開物の一覧と取り下げ — 何を公開したかを一覧でき、取り下げもできます

バケットは private と public を物理的に分離します。 公開バケットは read-only でマウントされるため、Finder から直接ファイルを置いて Exif 除去を迂回することが構造的にできません。公開は必ずアプリの共有ダイアログを通ります。

インストール

  1. Releases から SkyFolder.dmg をダウンロード
  2. DMG を開き、SkyFolder.app を Applications へドラッグ
  3. 初回だけ、下の手順で macOS の警告を越えます
  4. 起動するとオンボーディングが開くので、R2 の接続情報を入力します

初回起動時の警告について

現在の配布物は ad-hoc 署名で、Apple の公証（notarization）を受けていません。 そのため Gatekeeper がこのアプリを拒否し、ダウンロード直後はダブルクリックで開きません。

開くには次の手順を踏みます。

  1. Applications の SkyFolder.app をダブルクリック →「開発元を確認できません」→ そのまま閉じる
  2. システム設定 → プライバシーとセキュリティ を開く
  3. 下の方に出る「"SkyFolder" は開発元を確認できないため、使用がブロックされました」の横の 「このまま開く」
  4. 確認ダイアログで 「開く」

一度許可すれば以降は普通に起動します。 バンドル自体は壊れていません（codesign -v --deep --strict は通ります）。 拒否されるのは Developer ID 証明書と公証チケットが無いことだけが理由です。

知っておくべきこと

隠さずに書きます。使う前に把握しておいてください。

  • 公開バケットは秘匿性ゼロです。 key を知れば誰でも読めます。取り下げは削除ではなく gone/ への移動です
  • 期限付きリンクは発行後に取り消せません。 署名はローカル計算で完結し、サーバに状態を持たないためです
  • 保存 ≠ 即クラウド同期です。 反映は 30 秒程度かかります。アプリは「未送信 N 件」として表示します
  • 単一利用者・単一 Mac が前提です。 localhost の NFS は認証なしで待ち受けるため、共有 Mac では使わないでください
  • 公開バケットは OS レベルでは read-only ボリュームになりません。 Finder は書けると認識してドラッグを許可し、そのあと失敗します。異常ではありません
  • App Store では配布できません。 子プロセス実行と任意パスへのマウントのため App Sandbox を無効にしており、構造的に不可能です

現在の未検証事項

実 R2 アカウントでの通し確認（SigV4 の成立・presigned の実失効・Cache-Control の実付与）は まだ実施していません。検証スクリプトは同梱してあります。 また Apple Developer Program に未加入のため、公証と、画面ロック中の認証情報保護 （data protection keychain）も未達です。 詳細は STATUS.md に確定事項と未確定を分けて置いてあります。

よくある質問

macFUSE や kext は必要ですか？

要りません。macOS 内蔵の NFS クライアントを使う nfsmount 方式なので、カーネル拡張もドライバもインストールしません。

ターミナル操作は必要ですか？

アプリの利用には要りません。ただし公証が無いため、初回起動時だけシステム設定から手動で許可する操作が要ります（ターミナルは使いません）。

公開した画像から位置情報は消えますか？

消えます。GPS・Exif・IPTC・PNG のテキストチャンクなどの識別情報を、公開前に除去します。除去を無効にする設定は存在しません。

期限付き共有リンクは後から取り消せますか？

取り消せません。presigned URL はサーバに状態を持たないためです。期限は最大 7 日です。

保存したファイルはすぐ反映されますか？

すぐではありません。VFS の write-back により 30 秒程度かかります。その間は「未送信 N 件」として表示されます。

ライセンスは何ですか？

MIT License です。利用・改変・再配布は自由で、著作権表示と許諾文を残すことだけが条件です。同梱している rclone も MIT License です。

R2 バケットはアプリが作ってくれますか？

作りません。既存のバケットへ接続するだけです。バケットの作成・API トークンの発行・カスタムドメインの接続は、Cloudflare のダッシュボードで先に済ませてください。
